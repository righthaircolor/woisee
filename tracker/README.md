# woisee · трекер голоса (прототип)

Отдельная папка, приложение не меняется. Использует `../voice3.js`, `../voiceform.js`, `../field.js` из main.

Три вкладки внизу, как в How We Feel:

- **Сегодня** — неделя кружками-формами сверху, вопрос «Как ты звучишь этим днём?», кольцо недели и кнопка «Замер». После замера в кольце форма дня.
- **Замер по экранам**: 1) где, по-твоему, звучит голос (тап по зоне переводит дальше) → 2) «а-а-а» 5 с звука → 3) сирена 11 с → 4) «с-с-с» до тишины → итог. На каждом шаге таймер, ▶/❚❚, назад, «Пропустить / Дальше»; по готовности ↻ «ещё раз». Без микрофона — демо-голос.
- **Месяц** — календарь из форм дней, листание месяцев, карточка выбранного дня.
- **Данные** — неделя / месяц / всё время с листанием: «Слышишь себя», диапазон, устойчивость, выдох (со сравнением с прошлым периодом), где звучит голос, слепок, графики.

`core.js` — зоны, силуэт, хранение, тестовая история, графики. `app.js` — экраны.
Замеры хранятся в localStorage `woisee-tracker-v1`. «Тестовая история» (150 дней) подмешивается и выключается на «Сегодня».
Границы зон (MIDI): 40 · 52 · 62 · 67 · 74 · 86. Микрофон только по https.
