# woisee · трекер голоса (прототип)

Отдельная страница, приложение не меняется. Использует `../voice3.js`, `../voiceform.js`, `../field.js` из main.

- **Замер дня** (~30 с): догадка «где я звучу» → «а-а-а» 5 с → сирена 11 с → «с-с-с» до тишины → итог.
- **Вертикаль резонанса**: силуэт из частиц, 5 зон по высоте ноты (+ немного по яркости тембра). Форма голоса всплывает на высоте зоны, цвет — нота с хроматического круга. Подписи «Тело / Чакры».
- **Месяц**: тестовые 30 дней или свои замеры (localStorage `woisee-tracker-v1`): слышишь себя, диапазон, устойчивость, выдох, слепок голоса, зоны по неделям, графики, формы по дням.

Границы зон (MIDI): 40 · 52 · 62 · 67 · 74 · 86 — примерные регистровые переходы.
Микрофон работает только по https. Без микрофона — кнопка «Демо».
