# woisee

Ежедневные занятия голосом на 15–30 минут: тело → дыхание → фонация → артикуляция.
По руководству на основе Christina Shewell, *Voice Work: Art and Science in Changing Voices*.

Веб-приложение: https://righthaircolor.github.io/woisee/

Работает офлайн после первого запуска. Прогресс хранится на телефоне; резервная копия — во вкладке «Прогресс».
