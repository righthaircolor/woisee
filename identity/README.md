# woisee · айдентика (черновик 1)

Живая страница айдентики: знак, надпись, поведение формы от голоса, состояния, цвет, след, картинка дня, носители, правила.

- `index.html` — страница айдентики
- `voiceform.js` — движок знака без зависимостей (частицы + микрофон). Можно подключить в приложение как есть
- `fonts.css` — Inter Tight (OFL), те же начертания, что в приложении

Принцип: тишина — материя рассыпана; голос собирает её в стоячую волну.
Высота → число лепестков (комфортная нота = 3 = знак), устойчивость → чёткость,
громкость → глубина, атака → толчок, длительность → плотность, пауза → рассыпание с отпечатком.

Микрофон работает только по https.
