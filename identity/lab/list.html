Текущее упражнение в списке

Раскрыта только папка с текущим упражнением, остальные собраны. Текущее упражнение обведено контуром из точек, которые медленно текут по кругу. Разделители, которые касаются контура, исчезают.

Завершите упражнение кнопкой или нажатием на «▶». После последнего упражнения блока его папка собирается, следующая раскрывается, и точки перетекают на её первое упражнение. Собранную папку можно открыть нажатием, чтобы посмотреть упражнения.

  1. Пройденные: зачёркнуты, галочка в круге.
  2. Текущее: контур из точек, крупнее название, кнопка «▶».
  3. Закрытые: прозрачность 42%, замок, нажатие не работает.
  4. Папка пройденного блока: собрана, счётчик «3/3» с точкой.
  5. Если свернуть папку с текущим упражнением, контур обводит её шапку.
